# 选中道具聚光高亮 · Sipplay v2

此包保留「制作选中道具聚光高亮效果」原版交互的最新修订。包含完整 SVG 材质、六件道具、金色聚光、光环、星尘、等级路径和头像联动；为一整个可交互页面。

## 如何体验

默认 Lv 0。选择顶部预览等级 2 / 5 / 10 / 12 / 15 / 20，首次达到等级时解锁对应道具；点击已解锁道具切换选择。当前选中的道具、文字和聚光一起高亮，其他已获得道具保持常亮，未获得道具置灰。20 级道具未获得时保持预告常亮且不显示锁。

再次点击已获得道具仅移动聚光与路径，不重播开锁。未获得文案使用原稿，获得后变为 View Thought > / View Letter > / View Photo >。保留原版位置、尺寸、头像路径和灯光节奏。

## 接入

下载 prop-spotlight.html 可独立打开，图片和 SVG 都已内嵌，不依赖网络运行时。index.html 额外包含下载入口。relic-spotlight-source.html 是跨对话找到的原版源码快照，仅供研发追溯。

页面主体根节点是 #relic-spotlight，所有效果样式均以该节点限定范围。迁入业务页面时，保留该节点里的 SVG 图层及原脚本初始化顺序；每页默认一个实例。items 数组定义六件道具的等级、位置和命中区域；currentLevel 表示当前等级；selected 表示当前选中序号 0…5（-1 表示未选中）；render() 根据状态刷新聚光、文字和路径。将预览等级 change 处理替换为业务等级更新，命中按钮 click 处理用于业务选择。

开锁动画沿用 animateUnlock()，与 render() 的选中高亮分开。不要把聚光重新绑定到 newlyUnlocked；光束应跟随已获得且 selected 匹配的道具。组件中的示例文案与物品素材来自原稿，业务接入时由研发替换。

画布按 375 × 812 等比缩放，页面可滚动。系统减少动态效果时直接呈现状态并关闭装饰动画。此包是 Web 版本；其他对话中的 SwiftUI 工程不包含在此源码包内。
