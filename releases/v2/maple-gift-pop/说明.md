这是按参考 HTML「礼盒轻弹 · Sipplay v2」标准，为用户提供的枫叶礼盒图标制作的动效候选，**尚未经过真实浏览器视觉验收**，不能当作已通过。

## 交付路径

- 打开方式：用浏览器直接打开该文件。可选 `?compact` 进入 260×220 紧凑预览。

## 图标是什么

用户 SVG（35×29，`source/target-icon.svg`）是一款**带橙红色枫叶的礼盒**：粉橙礼盒、金色蝴蝶结与竖缎带、左上与右上共三颗金色星辰、左下贴着一片枫叶。几何与参考礼盒几乎同一坐标系，只是画幅更大以容纳枫叶，盒身配色更偏橙粉。

## 参考里实际采用的标准（不是只看标题）

解析参考 HTML 后的真实参数：

- 自定义元素 + Shadow DOM；宿主 44×44，图标 32×26；本候选按同等留白改为宿主 48×48，图标 35×29。
- 常态：三颗星辰持续闪烁，周期 1.8s / 2.35s / 2.1s，相位偏移 -0.4s / -1.15s / -0.7s，缩放与透明度在约 0.7–1.22、0.5–1 之间，easing 为 `cubic-bezier(.4,0,.2,1)`。
- 轻弹时长默认 **0.48s**（属性 `duration`，限制 0.3–2），自动间隔默认 **1.4s**（属性 `interval`，限制 0.8–10）。
- 盒身 `gift-pop`：先下压拉宽（9%：`translateY(.35px) scale(1.06,.92)`），再上弹拉长（32%：`translateY(-2.2px) scale(.95,1.05)`），随后回落微震，回到原位。原点取盒底中心。
- 盒盖 `lid-pop`：前 9% 随盒身下压保持闭合，34%–44% 抬起并旋转 -21°（`translate(.45px,-1.3px)`），再回落带 -1.5° 余振。原点在盖左铰链附近 `(9.6, 15.2)`。
- 迸发：4 颗星芒 + 9 颗彩斑，自蝴蝶结一带向上散开，约 10%–13% 才出现，约 74%–77% 收尽；easing `cubic-bezier(.08,.9,.2,1)`；带金/粉 drop-shadow。
- 点击在未播放时可立即触发；页面不可见时暂停，回来后恢复；`prefers-reduced-motion` 下停掉动画。
- 参考实现里，播放中的点击会被忽略。本候选按交接要求改为**最多排一轮**，不在中途重开动画，避免连点瞬跳或叠加失控。

页面提供 4× 细节预览、原尺寸 35×29 与原稿对照、重播、自动开关，按钮可键盘聚焦。

## 本图标的分层

在不改用户路径数据、颜色和造型的前提下分组：

- `star-0/1/2`：三颗原有星辰，在礼盒组外独立闪烁（与参考相同）。
- `gift`：整体轻弹，原点 `(19.94, 25.741)`（盒底中心，与参考一致，枫叶随盒身轻微挤压）。
  - `body`：盒身四层填色 + 竖缎带下段。
  - `lid`：盖瓣、蝴蝶结、盒盖、竖缎带上段、结扣。随盖掀起。
  - `leaf`：枫叶（本图标多出的结构）。同周期轻颤，峰值约 36%：`translate(-.7px,-1.15px) rotate(-14deg)`，弱于盒盖，略晚于盖的 34% 峰值。
- `burst-items`：参考同款星芒与光斑，坐标落在同一蝴蝶结区域，不随盒身缩放。

竖缎带是唯一做了几何拆分的路径：原稿是一条从 `y=10.2256` 到 `25.7408` 的矩形。为让盖掀起时缎带上下段能分开（参考也是如此处理），将不透明金带（paint19）拆成盖段 `10.2256–15.2685` 与身段 `13.752–25.7408`；半透明高光（paint20）在 `15.2685` 对接、不重叠，以免静止态高光叠深。其余 24 条 path 与全部 `<defs>` 与原稿逐字相同。

## 触发与连点

- 自动播放默认开启，间隔 1.4s；可关掉。关掉后星辰仍闪烁，点击和重播仍可用。
- 点击或重播：若当前未播放则立即开始；若正在播放则只标记再排一轮，等本轮 `gift-pop` 结束（或 duration+80ms 兜底）后再播，不会中途 `class` 重开导致跳回第 0 帧。
- 页面隐藏时暂停全部动画并取消排期；回到前台后，若自动开启则约 800ms 后继续。

## 已做的静态检查（不是浏览器视觉验收）

- 主脚本 `node --check` 通过。
- 组装 SVG 可被 XML 解析；23 个渐变 `id` 与全部 `url(#…)` 引用一一对应，无重复 id。
- 页面无外链；`</script>` 未被 SVG/字符串提前闭合（嵌入字符串将 `<` 写成 `\u003c`）。
- 原稿对照的 data URI 与源 SVG 字节级一致。
- 用 cairosvg 在 20×（700×580）下对比「去掉迸发的静止组装稿」与原稿：差异 186/406000 像素（0.0458%），最大通道差 38，几乎都在缎带拆缝 `y≈15.27` 的一行抗锯齿上。放大差分见 `preview/rest-diff-amplified.png`。
- 用烘焙变换渲染了约 34%–44% 峰值静态帧（`preview/peak-pose.png`）：盒盖左转掀起、结与上缎带跟随、下缎带留在盒身、枫叶轻转、星芒光斑在结附近。该帧没有 CSS drop-shadow，也未叠星辰闪烁相位，只用于结构核对。

## 限制

- 没有在真实浏览器里播放，也没有逐帧保证。CSS 动画、焦点、连点排队、`prefers-reduced-motion`、4× 缩放与溢出，都需要之后用浏览器打开上述 HTML 验收。
- cairosvg 不能复现播放中的滤光与时序，峰值 PNG 只是姿态参考。
- 缎带拆分会在高倍栅格化时留下几乎看不见的接缝；1× / 4× 实机观感需浏览器确认。
- 枫叶轻颤是按结构新增的从属运动，参考原件没有这层。
