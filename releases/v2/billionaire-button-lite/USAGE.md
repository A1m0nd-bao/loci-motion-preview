# Billionaire · 按钮选中切换

- 打开 `index.html` 预览，或下载 `billionaire-button-lite.html` 单独打开。
- 点击 Billionaire 切换选中与未选中；“重播”从未选中播放到选中。
- 勾选“慢速”后，播放速度约为正常速度的 1/2.8。

图形基准为 156×51，预览按 2 倍显示，窄窗口自动缩小。
已移除点阵背景，统一为纯深色。按钮内贴图、文字轮廓和原始动画逻辑保持不变。
图片及代码全部内嵌，无外部依赖。支持系统“减少动态效果”。

这是选中状态演示；真实接入时将 `.hm-button` 的 `aria-pressed` 状态与业务选择关联。
`?compact=1` 可显示仅按钮的紧凑预览。
