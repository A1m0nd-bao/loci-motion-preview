### 动效时序与物理曲线

| 动效分层 | 动画名称 | 时长 | 曲线 (Easing) | 机制说明 |
| :--- | :--- | :--- | :--- | :--- |
| **箱体** | `bodySquashOpen` | 0.68s | `cubic-bezier(0.2, 0.9, 0.3, 1)` | 14% 蓄力微蹲下压 (Y: +3.5px, scale: 1.06, 0.92) ➔ 36% 向上爆发弹跳 (Y: -4px) ➔ 65% 回弹缓冲 ➔ 稳定归位 |
| **箱盖** | `lidBounceOpen` | 0.75s | `cubic-bezier(0.18, 0.95, 0.3, 1)` | 12% 预备微压 ➔ 42% 爆发弹跳掀开 (Y: -35px, rotate: -11.5deg) ➔ 70% 缓冲 ➔ 稳稳停靠 (rotate: -8.17deg) |
| **爆出物** | `popFromCenter` | 0.65s | `cubic-bezier(0.18, 1.2, 0.32, 1)` | 所有彩带与彩纸以宝箱口中心 `(114, 160)` 为原点，scale: 0.08 爆发升腾至 scale: 1 并伴随微回弹 |
| **错落时序** | `animation-delay` | 0.08s ~ 0.30s | Staggered | 左彩带 (0.08s) ➔ 纸屑1 (0.12s) ➔ 纸屑4 (0.16s) ➔ 右彩带 (0.22s) ➔ 纸屑2 (0.26s) ➔ 纸屑3 (0.30s) |
| **原路收回** | `retractToCenter` | 0.30s | `cubic-bezier(0.4, 0, 0.7, 0.2)` | 点击合上时，爆出物原路吸回宝箱中心 (114, 160)，箱盖回落合上 |

### 交互 API
- 切换开合：给容器添加/移除 `chest-open` 与 `chest-close` 类。
- 可选自动循环：在后台或预览模式下周期性切换。
- 无声纯净动效：已彻底移除任何音频合成，完全无噪。
