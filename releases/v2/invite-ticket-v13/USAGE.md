# 邀请码奖券 · 向下撕开（v13）

- 打开 `index.html` 预览，或直接打开 `invite-ticket-demo-v13.html`。
- 输入非空邀请码，点击右侧蓝宝石奖励区域或按 Enter，播放副券向下撕开动效。
- 点击“重播”重新播放；勾选“过期状态”查看不可兑换状态。
- 支持 URL 参数 `?expired=1` 和 `?code=HELLO200`，参数需加在原始 HTML 地址上。

原始 HTML 的脚本和图片均已内嵌，上传时未改变源文件。
票券基准尺寸为 852×220，页面按容器宽度自适应。撕开动画时长约 1.25 秒，不含模拟请求等待。

这是交互演示，不会实际兑换奖励；非空邀请码默认通过。真实接入需连接业务校验及兑换接口。
页面内置重播、过期与减少动态效果的处理。
