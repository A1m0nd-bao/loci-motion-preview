# Sipplay Plus 碰杯弹窗

打开「碰杯弹窗.html」即可预览，图片已内嵌，无需联网或安装依赖。默认每 5.2 秒循环一次。工具栏仅保留重播。

## 动作与交互

- 0–0.47 秒：两手举杯前的轻微蓄势。
- 0.47–1.14 秒：双杯靠近；1.14 秒碰杯，点亮小星光，边缘暖光轻微提亮。
- 1.14–1.61 秒：小幅回弹并稳定。
- 1.61–3.80 秒：停留，背景暖光小幅呼吸。
- 3.80–5.20 秒：双手退回准备位，平滑进入下次循环。
- Done：按压反馈与涟漪，220 毫秒淡出关闭；通过工具栏重播可重新打开。Escape 也可关闭。
- 系统开启减少动态效果时，取消碰杯循环和呼吸闪光。

## 文件

- 碰杯弹窗.html：自包含的交互式预览，CSS + 原生 Web Animations API，无外部依赖。
- 碰杯动效预览.mp4 / .gif：供评审的循环片段；按钮交互请查看 HTML。
- 碰杯图标-分层.svg：两层透明位图嵌入 SVG，可作为设计工具导入素材；未在 Figma 内实际验证。
- assets/left-hand-glass.png、right-hand-glass.png：各自为 868×1012 的透明画布，使用时均显示为 434×506、坐标 0,0，可直接叠放。
- assets/reference.png：用户提供的原始参考。
- layers.json：相对原始生成图的尺寸和配准信息。
- imagegen-prompts.json：内置 ImageGen 使用的完整拆分提示词。

上方图标使用内置 ImageGen 提取和补全，按左右两组保留手与酒杯的刚性关系。杯沿和手指等局部与参考有轻微差异，不是逐像素切图。弹窗底板、文字、按钮与光效通过代码重建；保留原始英语文案及 {amount} 占位符。

## 接入

舞台以 434×506 为逻辑尺寸。图片在统一坐标系中摆放，左右手的旋转中心分别为 (64,184) 和 (366,174)。更改整体大小请统一缩放舞台，避免只缩放某一图层。按钮关闭后抛出 document 的 sipplay:done 事件，detail 为 { action: "dismiss" }，可绑定业务回调。

预览工具栏位于 section.scene 外，接入实际产品时可移除工具栏、标题和提示。实际订单、支付及会员状态更新需接业务逻辑，本演示仅实现弹窗动效和关闭交互。

## 验证

Chrome：960×820 与 390×760，校验图片加载、碰杯关键帧、Done 关闭、再次播放、Escape、单一重播入口及减少动态效果。页面无横向溢出。未测试 Safari、实际 App WebView 和真实业务接入。
