# 光效跳动修复说明（v2，2026-11-23）

基线：`popup-motion-simplified.html`。候选：`popup-motion-simplified-v2.html`。未改站，未做浏览器实播。

入场编排未改：主窗口 0–400ms 单段弹出；按钮与光 400ms 同步开始；按钮单段淡入+8px；光只做透明度显现，无过冲或缩放弹动。关闭热区等未要求事项未改。

## 原机制与根因（有采样证据）

入场结束（t=780ms）时，`#popup-rays` 为 scale=1、rotate=0、opacity=1，各束也是静态恒等变换。随后同一帧 `setRaysLoop(true)`：

1. 给 `html` 加上 `is-rays-loop`，CSS 循环立刻生效。
2. `ray-spin` 从 `from { rotate(-8deg) }` 起算（无相位偏移），整组光瞬间从 0° 跳到 -8°。
3. `ray-fan` 的 `from` 是 `scale(0.97) rotate(-1.4deg); opacity: 0.62`。ray0 delay=0，直接跳到该值。ray1–5 带负 delay（-1.2s 至 -5.7s），一上来就落在循环中段，姿态各不相同。
4. 同一函数对 spin + 6 束各做一次 `animation: none` + `getBoundingClientRect()` 强制重排后再重开动画，交接帧有同步布局成本，表现为卡顿。

静态采样（CSS `ease-in-out` = cubic-bezier(0.42,0,0.58,1)；这是代码模型，不是实播）在 t=779.9→780ms：

| 束 | Δscale | Δrot（含整组 -8°） | Δopacity |
| --- | --- | --- | --- |
| ray0 | -0.0300 | -9.4000° | -0.3800 |
| ray1 | -0.0249 | -9.2428° | -0.3587 |
| ray2 | -0.0102 | -8.7832° | -0.2963 |
| ray3 | +0.0173 | -7.9290° | -0.1804 |
| ray4 | +0.0346 | -7.3918° | -0.1075 |
| ray5 | +0.0406 | -7.2032° | -0.0819 |

这就是「跳转一下」。父层 JS transform 在结束时已卸掉，问题不在入场关键帧，而在入场静止态与循环第一帧不对齐。

## 修改（最小）

1. `#popup-rays-spin` 使用 `animation: ray-spin 16s ease-in-out -8s infinite alternate`。路径仍是 ±8°，但相位从中点 0° 起（`ease-in-out` 在 50% 处值为 0.5），与入场结束对齐。
2. `ray-fan` 改为闭合关键帧，0%/50%/100% 都是 `scale(1) rotate(0) opacity 1`（入场结束态），25% 仍到 `1.06 / 1.4° / 1`，75% 仍到 `0.97 / -1.4° / 0.62`。取消 `alternate`，周期改为原来的两倍（12.8–16.8s），让两端往返节奏接近原 6.4–8.4s 单程。各段自带 `ease-in-out`。
3. 去掉各束负 delay，避免开场就落在中段；错开改由不同周期自然形成。
4. `setRaysLoop` 只切换 class，不再在交接帧对 7 个节点强制重排。
5. 入场完成的那一帧先画出静止态，下一帧再挂上循环 class。

## 边界采样（模型，非实播）

V2 以 16ms 帧为例：入场完成 780ms，循环 796ms 才挂上。

- 779.9→780、795.9→796：六束 Δscale/Δrot/Δopacity 均为 0。
- 796→797（循环第一毫秒）：Δscale=0，Δopacity=0，Δrot=+0.0017°（16s 摆动在 0° 附近的正常速度，不是跳变）。
- 循环半周期：+8°、0°、-8° 处 0.5ms 步进的 spin Δ 约为 0 或 ±0.0009°，无反向跳变。
- 各束 100%→0%：scale/opacity Δ=0；合旋转仅剩 spin 的连续增量（约 ±0.0003–0.0004° / 0.25ms）。
- 16ms 步进、入场至循环后 40s：V2 最大相邻 Δscale=0.0005、Δrot=0.038°、Δop=0.063（后者出现在 t≈592，是 400–780ms 入场渐亮最陡处，不是交接跳变）。同条件 V1 最大值仍是交接帧的 0.041 / 9.40° / 0.38。
- 8/33/50ms 步进结论相同：V2 交接无跳，较大 Δop 都来自入场渐亮被粗步进切开（50ms 时约 0.195 @ t=600）。
- 循环起步 16ms 内 spin 仅 +0.028°。

`node --check` 通过。结构 id、文案、`#popup-config`、入场关键帧与关闭/CTA 交互均与 v1 一致。

待实播：入场结束后光是否仍会跳一下或卡一下；慢摆是否从当前姿态接上；重播、reduced-motion、显隐切换后循环是否正常。
