# 页面入场与角色选择 · 自然光感联动组件

Sipplay 游戏开场 2.0s 页面入场编排与 4 人分镜角色选择组件。基于纯原生 Web 标准（SVG + HTML5 + CSS 动画 + 原生 ES6 交互），同时附赠 React / Framer Motion 版本。

## 🌟 核心特性与动效设计

1. **两批依次平滑入场（2.0s 入场编排）**：
   - **第一批（分镜与立绘）**：底层黑紫渐变常驻 -> 4 组分镜格背景平滑缩放展开（0.10s - 0.40s）-> 4 位角色立绘自下而上轻快浮升（0.20s - 0.60s），单调减速曲线无生硬回弹。
   - **第二批（前段界面与选项）**：顶部标题优雅显现（0.75s）-> Male（0.85s）-> Female（0.95s）-> Non-binary（1.05s）-> Play Now 按钮（1.18s）依次浮升。
2. **全员不置灰（自然光感）**：
   - 未选中的角色保持 100% 原始色彩与饱和度（`opacity: 1.0, filter: none`），彻底摒弃暗化压灰。
   - 选中的角色展现契合场景的专属柔和光晕（冷白银蓝、暮色粉紫、温润金黄、壁炉暖光），并微浮升 6px（`translateY: -6px`）。
3. **性别双向随机高亮**：
   - 点击 **Male**：在机车男与耳机男之间随机点亮一名，再次点击智能切换至另一名。
   - 点击 **Female**：在手机少女与秋千少女之间随机点亮一名，再次点击智能切换至另一名。
   - 点击 **Non-binary**：激活非二元角色组，无缝切换为希利尔、泰勒、罗恩、卡米尔 4 套全新立绘与场景背景。
   - 点击**任意立绘**：精准直达对应角色并高亮其所属性别。
4. **原稿紫色浮升粒子**：
   - 严格保留设计稿 24 颗紫色环境粒子，匀速垂直浮升（`linear` 缓动）并平滑渐隐消散。

## 📐 规格参数

- **舞台尺寸**：`750 × 504`（自适应响应式缩放）
- **入场总时长**：约 `2.0 秒`
- **缓动曲线**：`cubic-bezier(0.16, 1, 0.3, 1)`（平滑减速，零反弹）
- **状态列表**：`["entrance", "male-select", "female-select", "non-binary", "char-focus"]`

## 📁 目录结构

- `index.html`：完整在线预览与展示舞台（自适应适配 v2 预览卡片）
- `character-select.html`：单文件独立导出版
- `CharacterSelect.jsx`：React + Framer Motion 生产级组件实现
- `assets/`：高清立绘切图与分镜背景（16 张 PNG 图片）
- `source.zip`：包含 HTML、JSX、所有高清素材与接入文档的完整交付包
