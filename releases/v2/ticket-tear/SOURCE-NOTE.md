# 源码包范围

这个压缩包里是已发布的 HTML，以及两份审计说明：`AUDIT.md`、`TEXT-V3.md`。

它不是从原稿重新构建的完整源码。包内没有构建脚本，没有 `node_modules`，也没有用来重生这页的原始 SVG 或位图工程。目录里若仍有较早的 `reference-full.svg`，那是先前的矢量参照，不是本文件的重建输入，也没有放进这个压缩包。

`index.html`、`ticket-tear.html`、`ticket-tear-restyle.html` 是同一份文件。`source.zip` 与页面里的 `ticket-page-restyle.zip` 是同一份压缩包。

`TEXT-V3.md` 写于这次浏览器核对之前，其中「未发布。无浏览器验收」只描述写那份说明时的状态。之后的核对范围写在 `USAGE.md` 和 `QA.md`。
