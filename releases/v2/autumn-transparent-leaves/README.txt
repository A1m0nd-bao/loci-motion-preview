autumn-motion-transparent.html
透明嵌入版：页面与动效层均为透明，不绘制宿主背景，也不使用全屏固定定位。请放到已设定宽高的容器或 iframe 中使用，图层会铺满该容器；叶片为 pointer-events:none，不会拦截点击或滚动。资源均内嵌，无需外部文件。

autumn-motion-black-preview.html
黑色预览版：与正式版同一套动效与适配逻辑，仅 html/body 使用 CSS 黑色背景，便于单独打开查看。黑色不是动效层的一部分。

适配说明
动效层铺满容器，不再按 1440×900 画布等比缩小后留边。叶片仍沿右上到左下（斜率 0.645）运动，并在容器外生成、从左侧或底部外离场。叶片大小按面积比缩放，限制在 0.52–1.35 倍（相对原 1440×900），避免手机把整场机械缩小到看不清，也避免超大屏叶片过大；数量随面积与叶片大小调整，以接近原版疏密。窗口缩放或横竖屏切换时会按新尺寸重算路径。

隐藏页面时暂停；系统开启 prefers-reduced-motion 时暂停。保留原有 build / fit / sync、paused、rate 与空格键暂停。
