# 红金宝箱 · 跃起开箱（v5）

- 打开 `index.html` 预览，或直接打开 `red-gold-chest-v5.html`。
- 初始为闭箱静止状态。点击宝箱或“打开宝箱”播放，结束后点击“重新打开”重播。
- 画布获得键盘焦点后，按 Enter 或空格也可播放。

动效约 1.4 秒，包含蓄力、跃起、开盖、宝石抬升与落定。播放中不会重复触发。
Canvas 基准为 1340×1190，预览内容最大宽度为 420 px，并按窗口自适应。
贴图已内嵌在原始单文件中；上传时未改变源文件。旧预览和下载地址继续可用。

系统开启“减少动态效果”时直接显示开箱终态。页面隐藏时会停止播放并显示终态。

## 接口

```js
await window.chest.ready;
window.chest.play();
window.chest.reset();
window.chest.seek(700); // 毫秒，0 到 1400
window.chest.state();
```

原始 HTML 地址加 `?qa=1` 可显示进度滑块；`?qa=1&pose=700` 可检查指定时刻。
