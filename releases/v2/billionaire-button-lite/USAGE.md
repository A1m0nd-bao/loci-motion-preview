# Billionaire · 按钮选中切换（tie-fixed）

打开 `index.html` 预览，或下载 `billionaire-button-lite.html` 单独打开。

- 点击 Billionaire 切换选中与未选中；重播从未选中播放到选中。
- 勾选“慢放”约为原速度的 1/2.8。
- SVG 基准尺寸为 173×51，默认 2 倍预览；窄窗口自适应。
- 保留原稿的纹理变形、图标与文字联动。页面去除点阵，使用纯深色背景。

图片与脚本均已内嵌，无外部依赖；支持“减少动态效果”。
业务选中状态需与 `.ub-trigger` 的 `aria-pressed` 对应。
`?compact=1` 显示仅按钮的紧凑预览。

本轮替换网站预览和单文件；已发布 v2 研发交付 ZIP 保持原快照，未重打包。
