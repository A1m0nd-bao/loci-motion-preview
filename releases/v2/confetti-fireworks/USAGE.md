# 物理礼花庆典系统 · Sipplay v2

真实物理礼花庆典动效组件，支持 **四角礼花筒** 与 **中心放射爆开** 双模式对比，包含完整动力学曲线（极速抛物线上冲 ➔ 滞空最高点翻卷减速 ➔ 优雅重力下落消散）。

```html
<!-- 直接引入纯 HTML / SVG 即可使用，零外部依赖 -->
<div class="ribbon-wrapper mode-cannons" id="ribbonScene">
  <!-- 礼花粒子与抛物线关键帧 -->
</div>
```

### 两种物理模式

| 模式 | 特性与轨迹 | 动力学设计 |
| :--- | :--- | :--- |
| **四角礼花筒** (`mode-cannons`) | 四角礼炮以不同倾角冲入空中，交汇于中上空 | 0.3s 极速斜冲高空 (Y: -220px) ➔ 滞空翻卷 ➔ 重力优雅飘落漫天消散 |
| **中心放射爆开** (`mode-radial`) | 从正中心核心弹芯 360° 全方位弹射爆开 | 极速全向展开 ➔ 空中舒展舒缓翻飞 ➔ 柔和重力漫天消散 |

### 核心物理参数
- **主彩带**：金色双色渐变主彩带（左下上冲）与粉紫渐变主彩带（右下上冲），具备自旋翻滚 (`rotateZ`, `skewX`) 质感。
- **几何彩屑**：多边形小彩带、圆形星点、菱形高光碎片，错落分布在四角不同发射源。
- **慢动作模式**：支持 0.4× 慢放倍率，清晰观察粒子空中翻滚轨迹。
- **无噪纯净设计**：已彻底剥离 Web Audio API 音效，完全静音、安全跨域。

### 交互 API
- 触发单次礼花：重置并添加 `mode-cannons` 或 `mode-radial` 类。
- 模式切换：通过 `setMode('cannons')` 或 `setMode('radial')`。
- 慢动作切换：添加或移除 `slow-motion` 类。
- 自动循环喷射：设置定时触发器。
