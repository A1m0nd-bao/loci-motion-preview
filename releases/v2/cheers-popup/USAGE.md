# Sipplay Plus · 碰杯弹窗

本轮按 2026-11-26 用户提供 HTML 原样更新。打开 index.html 或 cheers-popup.html；图片内嵌，无外部依赖。

## 动作与交互

- 循环周期 3.9 秒（原版 5.2 秒）。约 0–0.35 秒蓄势，0.35–0.86 秒靠近碰杯，约 0.86–1.21 秒回弹，1.21–2.85 秒停留，2.85–3.90 秒回到准备位。
- 暖光 core 在周期 23.5% 处达到 .72，pulse 在 22.5% 处达到 .24；其他动作沿用用户源码。
- Done 与 Escape 关闭，关闭后停止循环；重播重新打开。关闭发出 document 的 sipplay:done 事件，detail 为 { action: "dismiss" }。
- 系统减少动态效果开启时不启动碰杯、呼吸和闪光循环；保持静态结果与关闭按钮。

## 接入

舞台 434×506；左右手使用统一坐标系，旋转中心 (64,184) 与 (366,174)。整体缩放，不单独变更图层比例。保留 {amount} 英文占位符，真实会员/订单/支付/到账由业务接入，动画与关闭事件不代表支付成功。

window.cheersPreview 支持 seek(ms)、play()，并提供 duration 和 state。源码的工具栏只显示重播；嵌入产品可移除外部标签、工具栏与提示。

## 源码包与历史素材

源码包内的三个 HTML 和两份说明已同步本轮；原分层图片、SVG、layers.json、生成提示词保持不变。MP4、GIF 和预览 PNG 是上一版评审快照，未重新录制，不作为 3.9 秒新版节奏的依据，以 HTML 为准。旧图片生成与配准信息沿原包保留。

## 验证边界

本轮复核 Web 图片加载、3.9 秒时间线、碰杯画面、Done/Escape 关闭、重播、窄屏、键盘焦点和减少动态效果。实际测试环境和截图以本轮交付记录为准；未验证 Safari、原生 App/WebView 或真实支付业务。v2 总交付 ZIP 保持原冻结快照。
