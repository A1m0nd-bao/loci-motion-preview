# 豪华奖励迸发 · 宝箱两态动效组件 · Sipplay v2

Sipplay 开箱与豪华奖励迎新（Welcome Gift）2.6s 完整两态编排动效组件。纯原生矢量标准实现（SVG + 高精度 Path 形变 + 原生 ES6 插值引擎），零位图噪点，全分辨率无损缩放。

## 🌟 核心特性与分段编排

1. **2.6s 完整物理动力学编排**：
   - **① 静止待启（0.00s – 0.15s）**：宝箱闭合稳固待命，呈现沉静内敛质感。
   - **② 蓄力充能 · 内部高压（0.15s – 0.48s）**：箱体受内部能量蓄力挤压，伴随高频微颤抖动（Pre-blast rumble jitter，振幅 1.6px）。
   - **③ 轰然爆发 · 宝物涌现（0.50s – 0.70s）**：箱盖瞬间形变爆开（Snap Lid Morph），伴随全屏镜头冲击震颤（Camera Screen Shake，垂直冲击峰值 5.5px，水平 2.2px），核心爆光闪现、黄色环境光晕扩展、辐射光柱向上伸展。
   - **④ 奖励呈现 · 弹力落位（0.70s – 1.05s）**：9 颗独立水晶宝石解耦散落（顶部主晶石高弹 -17px，深层底座宝石稳固微弹），金券冲出箱口并在到达最高点后惯性弹跳落位。
   - **⑤ 好礼呈现 · 按钮激活（1.05s – 1.45s）**：底部 Claim 按钮微动弹入，光感收敛，进入待领交互状态。
   - **⑥ 礼成 · 待领取（1.45s – 2.60s）**：奖励定格待命，支持实时拖拽时间轴任意进度回溯审查。
2. **纯矢量插值与高性能计算**：
   - 基于离线生成的矢量关键路径采样（`DATA` 包含 49 处矢量形变曲线），通过 Smoothstep 缓动与 Lerp 线性插值实现极致流畅的 60fps 连续变形，无任何视频或 GIF 锯齿。
3. **控制面板与审查工具**：
   - 支持「播放 / 暂停」、「重播」、「首态直达」、「尾态直达」；
   - 0.001s 精度无级时间轴进度滑块与状态阶段指示器；
   - 1× 标准播放与 0.5× 逐帧慢放审查。
4. **外部控制 API**：
   - 挂载全局对象 `window.chestMotion = { seek(timeSeconds), duration: 2.60 }`，方便业务层接入生命周期与状态监听。
