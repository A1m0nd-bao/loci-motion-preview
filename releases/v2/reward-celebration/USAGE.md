# 奖励庆祝与聚光背光组件 · Sipplay v2

双宝石与单宝石动态聚光庆祝动效组件。支持 644×644 绚丽聚光背光（Backglow Enrichment）、星芒散射、放射光柱流光与数字步进跳跃。基于纯原生 Web 标准（SVG + HTML5 + CSS 动画 + 原生 ES6）。

## 🌟 核心特性与动效设计

1. **聚光背光编排（Backglow Enrichment）**：
   - **多层圆光氛围**：包含 170px 核心光晕（`#FFE6C2` 高亮）、280px 扩展光晕（`#FFDAA2` 金橙）、330px 外围弥散光晕（`#ED78F4` 暮紫与冷蓝过渡）。
   - **放射光柱（Light Rays）**：5 条高精度矢量放射光柱，由尖端至根部自然流动呼吸，零漂移。
   - **底座柔光（Pedestal Glow）**：双层柔光与核心高光托底，根据宝石尺寸自适应适配。
2. **单/双宝石布局自适应**：
   - **单类型奖励**：自动居中展示大号宝石模型，中央聚光汇聚；
   - **双类型奖励（红宝石 + 蓝宝石）**：自动分列左右双簇，左右分别拥有独立的背光与星星散射动画。
3. **数字步进与星芒交互**：
   - 包含动态粒子喷薄、星星闪耀（`centerStarsAnim`）与金额数值跳动。
4. **轻量化交付优化**：
   - 宝石素材转换为高保真 WebP，体积缩减 74%，单文件 HTML 仅 ~170KB，极速加载。

## 📐 规格参数

- **舞台尺寸**：`644 × 644`（自适应响应式缩放）
- **入场总时长**：约 `1.8 秒`（随后进入平稳呼吸循环）
- **状态列表**：`["entrance", "breathe", "dual-cluster", "single-cluster"]`
